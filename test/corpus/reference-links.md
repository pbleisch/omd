# Reference-style links

A [shortcut] reference, a [collapsed][] one, and a [labelled][full] one — all pointing at
definitions kept at the bottom of the file, where a writer put them.

Two references to [shared] and [shared] again share one URL, so there is one place to edit it.

A reference image: ![diagram]

A `[bracketed]` span in code and a plain [undefined] label are not references at all — there is
no definition for either, so they stay literal text.
